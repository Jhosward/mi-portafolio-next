# 🚀 Mi Portafolio Full-Stack (Next.js)

Portafolio profesional centralizado desarrollado con **Next.js (App Router)** y **Tailwind CSS**, creado para integrar y exhibir mis mejores proyectos de desarrollo web mediante arquitectura de componentes y navegación fluida.

## 📁 Proyectos Integrados

1. **E-commerce Streetwear:** Tienda virtual interactiva con catálogo de productos y carrito de compras dinámico.
2. **Buscador de Películas:** Aplicación interactiva desarrollada con TypeScript para búsqueda de películas en tiempo real.
3. **Mokepon Game:** Videojuego web interactivo desarrollado con HTML5, CSS3 y JavaScript.

## 🛠️ Tecnologías Utilizadas

* **Framework:** Next.js (App Router)
* **Estilos:** Tailwind CSS / CSS Modules
* **Lenguajes:** JavaScript, TypeScript, HTML5, CSS3
* **Control de Versiones:** Git & GitHub
